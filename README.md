IT Business Analysis coursework: use cases, REST API documentation, JSON structures, and Database design.
Online Restaurant Reservation System

Project Overview
This individual educational project was completed as part of IT Business Analysis coursework at Ingress Academy.
The project focuses on analyzing an online restaurant reservation system that allows customers to browse restaurants, view restaurant details, create reservations, view reservation history, and cancel reservations.

Note: This project focuses on business analysis, API documentation, and database design. A functional application and a live API have not been implemented.

Project Scope
- Project Overview
- As-Is and To-Be Process Analysis
- Use Case Documentation
- REST API Endpoint Documentation
- JSON Request and Response Structures
- Database Design (ERD)

API Documentation
The API documentation describes the proposed endpoints, HTTP methods, and example request and response structures for restaurant and reservation operations.
The endpoint definitions and JSON structures are documentation examples and do not represent a tested or live API.

Database Design
An entity-relationship diagram (ERD) was prepared to represent the proposed database structure, entities, and relationships.
